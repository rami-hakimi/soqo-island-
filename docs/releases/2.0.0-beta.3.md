**Soqo Island 2.0.0-beta.3 — fixes from the first beta days (pre-release)**

Soqo Island is a floating desktop companion for Windows 10 and 11: a small glass capsule at
the top of the screen with music controls, timers, downloads, notifications, productivity
tools and Soqi the Dolphin. English, Arabic and Dutch. This is a **beta pre-release**.

## Fixed
- **The island stays where you put it.** In beta.2 the "browser address bar" slot moved the
  island into whichever Chromium window was in front, which could land it in the middle of the
  screen. That slot is now opt-in (Settings › General › Browser address bar) and was switched
  off once for existing installations. The island keeps its top-centre place, or the spot you
  dragged it to, across app switches, Settings and restarts.
- Address-bar detection, for those who turn the slot on, ignores text fields on web pages and
  skips the slot when the address bar is not fully on screen.

## Added
- **Hide while an app is maximized** (Settings › General, off by default). With "Keep a
  running timer visible in full screen" on, a running timer stays visible in both cases; the
  timer keeps counting while the island is hidden.
- **Legal notices inside the app** (Settings › Legal): the GPL-3.0 licence, the notices and
  credits, and the third-party licences shipped with this copy.

## Changed
- Larger running-timer pill in all three sizes, with bigger digits and pause/reset targets.
  Colours are unchanged.
- Developer name shown as Rami Al-Hakimi.

## Installation
Download `Soqo-Island-Setup-2.0.0-beta.3.exe` (checksums in `SHA256SUMS.txt`) and run it.
**The installer is not code-signed, so Microsoft SmartScreen may warn**; continue only for a
file downloaded from this Releases page. Installing over beta.2 keeps your settings; beta.2 users
with Auto-update on are offered this version automatically.

## Known limitations
- Unsigned installer. Arabic and Dutch translations still await a native-speaker review.
- Tested primarily on one Windows 11 machine at 125 % scaling with a single monitor.

Report bugs through [GitHub Issues](https://github.com/rami-hakimi/soqo-island-/issues).
