**Soqo Island 2.0.0-beta.4 — timer and visibility update (pre-release)**

Soqo Island is a floating desktop companion for Windows 10 and 11: a small glass capsule at
the top of the screen with music controls, timers, downloads, notifications, productivity
tools and Soqi the Dolphin. English, Arabic and Dutch. This is a **beta pre-release**.

## Fixed
- **A hidden island can always be brought back.** Starting Soqo Island again while it is
  already running now reveals the island (it used to do nothing), the island's menu and the
  tray menu say **Hide island** or **Show island** depending on the current state, and a
  double-click on the tray icon shows the island too. When a full-screen or maximized rule is
  keeping it hidden, a second start tells you so in a notification instead of staying silent.
- A Focus Mode view or a maximized-window rule can never hide the island for good: it returns
  as soon as the view closes or the window in front changes.

## Added
- **Adaptive timer pill.** The size you pick under Settings › Timer is the *desktop* size.
  When another application comes to the front (a browser, Explorer, an editor), a running timer
  shrinks to a compact 168 × 28 pill at the same spot, clear of tabs and toolbars, and grows
  back when you return to the desktop. Short, smooth transition; respects reduced motion; the
  countdown is never touched. The full-screen and maximized rules keep their precedence.
- **Focus Mode.** A full-screen, distraction-free countdown on the island's display with huge
  digits, a progress bar, Pause / Resume, **Exit Focus Mode** (Esc) and **Cancel timer**, plus
  the same presets and focus-session start as the Timer tab when nothing is running. Open it
  from the Timer tab's new button or the island / tray menu. Esc leaves the view with the
  timer still running; it is an ordinary window, so Alt+Tab and every Windows shortcut work.
  The island waits while the view is in front and comes back the moment you switch away.

## Changed
- **Large is genuinely large**: 400 × 88 with 64 px bold digits and 44 px pause / reset
  targets (was 324 × 66 with 48 px digits). Small (300 × 38) and Medium (260 × 50) are
  unchanged. Colours are unchanged.
- The helper also reports whether the desktop or the taskbar is the window in front (only the
  window class is read; see `docs/PRIVACY.md`).

## Installation
Download `Soqo-Island-Setup-2.0.0-beta.4.exe` (checksums in `SHA256SUMS.txt`) and run it.
**The installer is not code-signed, so Microsoft SmartScreen may warn**; continue only for a
file downloaded from this Releases page. Installing over an earlier beta keeps your settings,
position, timers and optional features; users with Auto-update on are offered this version
automatically.

## Known limitations
- Unsigned installer. Arabic and Dutch translations still await a native-speaker review.
- Tested primarily on one Windows 11 machine at 125 % scaling with a single monitor.

Report bugs through [GitHub Issues](https://github.com/rami-hakimi/soqo-island-/issues).
