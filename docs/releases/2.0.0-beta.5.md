**Soqo Island 2.0.0-beta.5 — battery, weather credit, coding agents, Activity tab, Windows notifications (pre-release)**

Soqo Island is a floating desktop companion for Windows 10 and 11: a small glass capsule at
the top of the screen with music controls, timers, downloads, notifications, productivity
tools and Soqi the Dolphin. English, Arabic and Dutch. This is a **beta pre-release**.

## Added
- **Battery** in the System tab, under Brightness: percentage, charging / plugged in / on
  battery / fully charged, low and critical states, and the time left when Windows knows it.
  Read straight from Windows through the helper; PCs without a battery simply do not show the
  row, and an unknown reading is shown as unknown rather than guessed.
- **Coding Agents** (opt-in, Settings › Connections). Connect **Claude Code** and/or **Codex
  CLI** and the new **Activity** tab lists their sessions: started, working (with the current
  tool), idle, finished, failed — and **needs your approval**, as a prominent toast with a safe
  one-line summary of the request, the agent, the project and the time. Clicking the row or
  the toast brings the terminal window the session runs in to the front; the approval itself
  is always given there. Everything is local: the agents' own hooks talk to the island over a
  token-checked named pipe, prompts and replies never leave the hook, and nothing is sent
  anywhere. Connect edits the agent's user-level hook file only after asking you, keeps a
  backup next to it, and Disconnect removes exactly Soqo Island's entries. Codex asks you to
  trust the new hooks once with `/hooks`. Details: `docs/CODING_AGENTS.md`.
- **Activity tab**: coding-agent sessions, most important first, and recent notifications.
- **Windows notifications on the island** (opt-in, Settings › Connections): the notifications
  Windows shows in its notification centre — Chrome web notifications such as WhatsApp Web
  included — through Windows' own notification listener. Windows' permission is asked for and
  shown, previews can be switched off, nothing is stored, Windows' do-not-disturb state is
  respected, and a notification dismissed in Windows disappears here too. Verified on Windows
  11 (build 26200) with the unpackaged installer; background and limits in
  `docs/WINDOWS_NOTIFICATIONS.md`.

## Changed
- **Weather card credit**: the large underlined attribution link is now a small
  "Weather by Open-Meteo" link plus an ⓘ control that opens an accessible popover with the
  provider, the CC BY 4.0 licence, licence details and the GeoNames city-search credit.
  Open-Meteo's licence requires a link next to its data, which is why the small link stays.
  The popover closes with Escape, a click elsewhere or when the island collapses, and never
  covers anything outside the island.

## Verification (2026-11-02, Windows 11 25H2 build 26200, 125 % scaling)
- `npm run verify` green: 82 scripts, ESLint, TypeScript `checkJs`, 599 keys in each
  language, unit tests including the new battery, agent-events, agent-config, agents-bridge,
  notifications and weather-attribution suites.
- Real Claude Code session (interactive, default permission mode, the island's hook entries
  loaded with `--settings`): start → working with `Bash: whoami /groups …` → **Needs your
  approval** toast within two seconds of the prompt → *Open terminal* brought the Windows
  Terminal window to the front → approved there → Finished. Repeated events were folded;
  the dev island received the SessionEnd on `/exit`.
- Windows notification: a test toast appeared on the island within four seconds and on the
  Activity tab.

## Known limitations
- Approvals are read-only on the island by design (see the roadmap for the reviewed
  approve/deny design).
- With several tabs in one terminal window, *Open terminal* brings the window to the front, not
  the specific tab.
- Chrome notifications do not expose the site origin, so a WhatsApp Web message appears as
  "Google Chrome · <title>".
- Unsigned installer; Arabic and Dutch translations of the new strings await a native-speaker
  review.

## Installation
Download `Soqo-Island-Setup-2.0.0-beta.5.exe` (checksums in `SHA256SUMS.txt`) and run it.
**The installer is not code-signed, so Microsoft SmartScreen may warn**; continue only for a
file downloaded from this Releases page. Installing over an earlier beta keeps your settings,
position, timers and optional features; the new integrations are off until you turn them on.

Report bugs through [GitHub Issues](https://github.com/rami-hakimi/soqo-island-/issues).
