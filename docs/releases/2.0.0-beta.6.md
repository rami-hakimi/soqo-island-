**Soqo Island 2.0.0-beta.6 — timers, Focus Mode, battery, coding agents, notifications, scrolling (pre-release)**

Soqo Island is a floating desktop companion for Windows 10 and 11: a small glass capsule at
the top of the screen with music controls, timers, downloads, notifications, productivity
tools and Soqi the Dolphin. English, Arabic and Dutch. This is a **beta pre-release**; it
gathers everything since beta.3 (beta.4 and beta.5 were development builds that were never
published).

## Highlights since beta.3
- **Adaptive timer pill.** The size you choose under Settings › Timer is the desktop size.
  When another application comes to the front, a running timer shrinks to a compact pill at
  the same spot, clear of tabs and toolbars, and grows back on the desktop. Large is now
  genuinely large (400 × 88 with 64 px digits).
- **Focus Mode.** A full-screen, distraction-free countdown on the island's display with
  Pause / Resume, Exit (Esc) and Cancel, the same presets and focus-session start as the
  Timer tab. Opened from the Timer tab or the island / tray menu; an ordinary window, so every
  Windows shortcut keeps working.
- **A hidden island always comes back.** Starting Soqo Island again while it runs reveals the
  island, the menus say *Hide island* / *Show island* by state, a double-click on the tray
  icon shows it, and a start under a full-screen or maximized rule explains itself.
- **Battery** in the System tab under Brightness: percentage, charging / plugged in / on
  battery / fully charged, low and critical states, time left when Windows reports it. Read
  straight from Windows; PCs without a battery simply do not show the row.
- **Cleaner weather credit.** The large attribution link became a small "Weather by
  Open-Meteo" link plus an ⓘ control with the provider, the CC BY 4.0 licence, licence
  details and the GeoNames city-search credit (Open-Meteo's licence asks for a visible link
  next to its data, so the small link stays).
- **Coding Agents** (opt-in, Settings › Connections). Connect **Claude Code** and/or **Codex
  CLI** and the new **Activity** tab shows their sessions: started, working (with the current
  tool), idle, finished, failed — and **needs your approval**, as a prominent toast with a safe
  one-line summary, the agent, the project and the time. Clicking brings the terminal window
  the session runs in to the front; the approval itself is always given there, never on the
  island. Local only: the agents' own hooks talk to the island over a token-checked named
  pipe; prompts, replies and transcripts never leave the hook; nothing is sent anywhere.
  Connect edits the agent's user-level hook file only after a confirmation dialog, keeps a
  backup next to it, and Disconnect removes exactly Soqo Island's entries. Codex asks you to
  trust the new hooks once with `/hooks`. Details: `docs/CODING_AGENTS.md`.
- **Windows notifications on the island** (opt-in, Settings › Connections): the notifications
  Windows shows in its notification centre — Chrome web notifications included — through
  Windows' own notification listener. Windows' permission is asked for and shown, previews
  can be switched off, nothing is stored, do-not-disturb is respected, and a notification
  dismissed in Windows disappears here too (`docs/WINDOWS_NOTIFICATIONS.md`).
- **Scrolling throughout the island.** Content that does not fit a panel now scrolls inside
  its card — System meters (so Battery is always reachable), Clipboard, the Activity lists,
  pinned apps, app search, Downloads and the prayer list — with mouse wheel, touchpad and
  keyboard (click a list's surface, then arrow keys / Page Up / Page Down). The island keeps
  its size and place; a drag on a list or its scrollbar never moves it. Works in English,
  Arabic (right-to-left) and Dutch.
- **Clipboard history** keeps 20 entries (was 8), in memory only.
- **Localization and accessibility:** Arabic and Dutch strings for every new feature, named
  and keyboard-focusable lists and controls, reduced-motion support kept, clear empty states
  on the Activity tab.

## Known limitations
- **Codex interactive integration still needs the owner's own test run:** the Codex hook
  entries and the relay were verified with Codex-shaped events, but a live `codex` session
  with trusted hooks has not yet been exercised end to end. Claude Code was verified live
  (approval request, Open terminal, finish).
- **WhatsApp Web notifications appear under "Google Chrome"** with the message title, because
  Chrome's toasts do not expose the site origin to Windows' listener. A WhatsApp Web PWA uses
  its own name.
- Approvals are read-only on the island by design. With several tabs in one terminal window,
  *Open terminal* brings the window to the front, not the specific tab.
- **The installer is not code-signed**, so Microsoft SmartScreen warns on first run.
- Arabic and Dutch translations of the new strings await a native-speaker review.
- Tested primarily on one Windows 11 machine (25H2, build 26200) at 125 % scaling with a
  single monitor; Windows 10 and multi-monitor set-ups are not yet validated.

## Installation
Download `Soqo-Island-Setup-2.0.0-beta.6.exe` (checksums in `SHA256SUMS.txt`) and run it.
**The installer is not code-signed, so Microsoft SmartScreen may warn**; choose *More info ›
Run anyway* only for a file downloaded from this Releases page, and check that the app name
reads Soqo Island. Installing over beta.2 or beta.3 keeps your settings, position, timers and
optional features; users with Auto-update on are offered this version automatically. The new
integrations (Coding Agents, Windows notifications) are off until you turn them on.

Report bugs through [GitHub Issues](https://github.com/rami-hakimi/soqo-island-/issues).
