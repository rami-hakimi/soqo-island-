**Soqo Island 2.0.0-beta.6 — scrolling fix (pre-release)**

Soqo Island is a floating desktop companion for Windows 10 and 11: a small glass capsule at
the top of the screen with music controls, timers, downloads, notifications, productivity
tools and Soqi the Dolphin. English, Arabic and Dutch. This is a **beta pre-release**.

## Fixed
- **The Battery row and long clipboard histories are reachable again.** In beta.5 a panel's
  content could grow past the island's bottom edge without any way to scroll to it: on laptops
  the System meters (CPU, Memory, Network, Brightness, Battery) overflowed the card, the
  clipboard list grew with its card instead of scrolling, and the mouse wheel over those
  areas changed the volume. Every panel now keeps the island's size and scrolls the content
  inside its card: System meters, clipboard, the Activity lists, pinned apps, app search,
  downloads and the prayer list. Mouse wheel and touchpad scroll them, a drag on a list or its
  scrollbar never moves the island, the last row is fully reachable and clickable, and a click
  on a list's surface gives it keyboard focus for the arrow keys and Page Up / Down (Escape
  hands focus back). Works in English, Arabic (right-to-left) and Dutch.
- Clipboard history keeps 20 entries (was 8), in memory only.

## Installation
Download `Soqo-Island-Setup-2.0.0-beta.6.exe` (checksums in `SHA256SUMS.txt`) and run it.
**The installer is not code-signed, so Microsoft SmartScreen may warn**; continue only for a
file downloaded from this Releases page. Installing over an earlier beta keeps your settings.
